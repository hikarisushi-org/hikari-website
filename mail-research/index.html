Find what you need in your own mail.

Joel Mail Research is a locally run tool for working with mailboxes controlled by its operator through an authorized agent client.

Separate account access. Each mailbox is authorized separately. The tool can search, read, draft, send, label, archive, and move messages to or from Trash. It does not permanently delete messages.

This information page is hosted on Hikari’s website. The mail tool runs separately on its operator’s Mac and is not part of the restaurant website.

How it works

The operator asks an authorized local agent to work with a specific mailbox. The tool checks that the Google account matches the requested mailbox before reading or changing mail, then returns the result to that agent for the operator's task. It is not offered as a public service.

Data practices

OAuth grants are stored in the operator's macOS Keychain. The utility does not create a mailbox-content database. An agent client may transmit returned mail data to its configured model provider to answer the operator's request; use is limited to clients with appropriate data controls.

Privacy policy · Last updated October 14, 2026

How mail data is handled.

This policy describes a private tool operated by Joel for mailboxes he controls. It requests the Gmail read-only permission separately for each mailbox.

What the tool accesses

At the operator's request, the tool reads the authorized account's profile identity, message lists, sender and recipient headers, subject, date, snippets, and the text of a selected message. The tool does not include attachments in its results. It cannot send, modify, archive, or delete mail.

Why it accesses data

Mail data is used only to answer the operator's requested searches and reads, including user-requested summaries. It is not sold, used for advertising, or used to build a training dataset.

Agent and model processing

The tool returns selected Gmail data to the local agent client chosen by the operator. That client may send the returned data to its configured model provider to answer the operator's request. The client provider's retention and processing follow its own settings and terms. The operator will use this tool only with agent and provider configurations that do not use Gmail data to train or improve general-purpose AI models. Use of information received from Google Workspace scopes will adhere to Google's User Data Policy, including the Limited Use requirements.

Storage and control

OAuth credentials are stored in owner-only files on the operator's Mac. This utility does not keep a separate mailbox-content database. Agent clients may keep conversation or tool history under their own settings. The account owner can revoke the app in Google Account security settings and remove the local token files.

Changes and contact

This policy will be updated before the utility accesses new types of Gmail data or changes how that data is used or shared. Contact: hello@hikarisojo.com.
